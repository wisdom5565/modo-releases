# MODO

업무일지 데스크탑 앱 MODO의 설치 파일을 받는 곳이에요. 코드는 여기에 없어요.

**[최신 버전 받기](https://github.com/wisdom5565/modo-releases/releases/latest)**

| PC | 받을 파일 |
| --- | --- |
| Mac (Apple 칩, M1 이후) | `MODO-<버전>-arm64.dmg` |
| Mac (Intel) | `MODO-<버전>.dmg` |
| Windows | `MODO.Setup.<버전>.exe` |

서명이 없어서 처음 열 때 경고가 떠요. Mac은 앱을 우클릭한 뒤 **열기**, Windows는 **추가 정보 → 실행**을 누르세요.

새 버전이 나오면 앱이 켜질 때 알려 줘요.
